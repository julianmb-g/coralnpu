> **Intended Audience:** Folks writing software

Covers the high-level flow of dispatching workloads to the NPU from a host CPU.

## Preparing the workload

Compile models (e.g., TensorFlow Lite) using the CoralNPU backend compiler. The compiler generates an ELF file containing vector instructions (RVV) and tensor commands (`mset*`).

## Loading the model

Allocate a contiguous block of system memory (or SRAM) and load the ELF binary. Set up the Command Ring Buffer in shared memory for asynchronous host-NPU communication.

## Execution

1. **Submit Commands:** Host application writes execution descriptors to the command ring buffer and updates the `head` pointer.
2. **Signal the NPU:** Issue memory fence (`fence`) and ring NPU doorbell (MMIO register write) to wake NPU.
3. **Hardware Fetch:** NPU's `FetchControl` unit pulls instructions via internal IBus.
4. **Processing:** Vector Core and Tensor Processing Engine (TPE) execute operations.

## Completion

NPU writes completion status to the command ring buffer and updates the `tail` pointer. Host application polls `tail` pointer or waits for PLIC interrupt.
