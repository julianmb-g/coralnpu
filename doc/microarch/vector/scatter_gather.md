# Vector scatter/gather hardware (scattergather.scala)

> **Intended Audience:** HW Devs, SW/Compiler Devs

The `Scatter` and `Gather` hardware blocks are combinatorial generator primitives defined in Chisel that facilitate non-contiguous memory access. They are integrated directly into the CoralNPU Load-Store Unit (`Lsu.scala`), which coordinates the multi-cycle execution loop across memory lines.

---

## Gather hardware primitive

The `Gather` block maps non-contiguous memory locations (from a single cache or SRAM line) back into a contiguous set of vector registers.

### Api and port interfaces

The `Gather` primitive is a combinatorial generator. It maps an array of indices to an array of fetched data elements.

| Port/Parameter | Direction | Type | Description |
| :--- | :--- | :--- | :--- |
| `valid` | Input | `Vec[Bool]` | Indicates if the corresponding data element and index are valid for the gather operation |
| `indices` | Input | `Vec[UInt]` | Array specifying the source index in the input data vector |
| `data` | Input | `Vec[T]` | Vector containing the input data elements to be gathered |
| `result` | Output | `Vec[T]` | The resulting vector after gathering the input data |

## Scatter hardware primitive

The `Scatter` block maps contiguous vector register elements into non-contiguous memory locations (within a single cache or SRAM line).

### Api and port interfaces

The `Scatter` primitive is a combinatorial generator. It maps an array of indices to an array of output data elements.

| Port/Parameter | Direction | Type | Description |
| :--- | :--- | :--- | :--- |
| `valid` | Input | `Vec[Bool]` | Indicates if the corresponding data element and index are valid for the scatter operation |
| `indices` | Input | `Vec[UInt]` | Array specifying the target index in the output vector for the corresponding data element |
| `data` | Input | `Vec[T]` | Vector containing the input data elements to be scattered |
| `result` | Output | `Vec[T]` | The resulting vector after scattering the input data |
| `resultMask` | Output | `Vec[Bool]` | Bitmask indicating which positions in the `result` vector were written to |
