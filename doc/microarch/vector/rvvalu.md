## Architectural Function
The `RvvAlu` (Vector ALU) module implements the primary execution unit for vector operations within the CoralNPU. It provides high-throughput arithmetic, logical, and permutation capabilities across a wide range of vector data types and precisions, processing instructions dispatched by the Vector Backend.

## Execution and Precision
The `RvvAlu` operates on a configurable `vtype` defined by the current vector register state, passed via `io.configState`.

- **Integer Precision**: Supports standard RISC-V Selected Element Widths (SEW) of 8, 16, 32, and 64 bits.
- **Floating-Point/BF16 Precision**: Supports specialized Brain Floating Point (BF16) precision for machine learning workloads, including widening (`is_widening`) and narrowing conversions.
- **Widening Operations**: Capable of executing instructions that operate on operands of different widths, facilitating mixed-precision arithmetic.

## Pipelining Stages
The `RvvAlu` implements a two-stage pipeline architecture to manage operation throughput:

- **Stage 0 (P0)**: Executes functional unit operations including Add/Sub, Shift, Mask, and other bitwise operations.
- **Stage 1 (P1)**: Executes remaining operations (handled by `rvv_backend_alu_unit_execution_p1`) and manages result arbitration and writeback to the Reorder Buffer (ROB).

[Source: `hdl/verilog/rvv/design/rvv_backend_alu_unit.sv`]

## Data Paths
- **Instruction Input**: Decoded instructions (`ALU_RS_t`) are received and processed by functional units in P0.
- **Result Writeback**: Valid results (`PU2ROB_t`) are arbitrated between P0 and P1 stages before being submitted to the ROB.
- **Side-Effects**: `vxsat` updates for saturation operations are propagated through the pipeline to the retirement logic.

[Source: `hdl/verilog/rvv/design/rvv_backend_alu_unit.sv`]

## Execution Side-Effects
- **Saturation**: Operations that saturate (e.g., `VSADD`) update the `vxsat` CSR when overflow occurs.
- **Masking**: Mask-driven operations (`vmask`) preserve inactive elements based on the state of the vector mask register.
