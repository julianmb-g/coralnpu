## Architecture Function Summary

The `intdivider` module implements an iterative division algorithm, specifically a shift-and-subtract approach. It utilizes a finite state machine to manage the division process through three phases: `DIV_IDLE`, `DIV_WORKING`, and `DIV_PRINT`. The divider is capable of handling special cases such as division by zero and signed overflow (e.g., `-2^(WIDTH-1) / -1`).
