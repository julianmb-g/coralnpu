## Description
The `Sram_Nx128` module is a parameterizable SRAM wrapper that aggregates multiple underlying `SramBlock` modules to achieve a desired depth, providing a consistent 128-bit data interface. It handles address decoding to select the appropriate `SramBlock` and manages the multiplexing of read data from the aggregated blocks.
