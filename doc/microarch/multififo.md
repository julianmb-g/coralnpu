## Overview

The `MultiFifo` is a parameterizable circular FIFO buffer that supports high-throughput data movement by allowing multiple elements to be enqueued and dequeued in a single clock cycle. It is used extensively in the CoralNPU backend to decouple modules with varying production/consumption rates.

| `fill_level` | Output | Current number of elements in the FIFO. |
| `data_out` | Output | Data vector available for dequeuing. |
| `ready_out` | Input | Number of elements being dequeued in this cycle. |

## Architectural Function

The `MultiFifo` implements a circular buffer with parameterized capacity (`MAX_CAPACITY`) and data width (`T`). It tracks occupancy using a `fill_level` register, which is updated atomically based on the `valid_in` (enqueue) and `ready_out` (dequeue) signals.

- **Enqueue:** Data is written to the buffer based on the `head` pointer and the `valid_in` count.
- **Dequeue:** Data is read from the buffer based on the `tail` pointer and the `ready_out` count.
- **Backpressure:** The FIFO enforces capacity constraints via assertions in simulation:
  - Enqueue must not exceed `MAX_CAPACITY - fill_level`.
  - Dequeue must not exceed `fill_level`.
