## Core Requirements

- **Host Interface**: Strict adherence to AXI4Lite as the standalone IP host interface.
- **ISA**: RISC-V Vector ISA, including BFloat16 extensions (`Zvfbfmin`, `Zvfbfwma`) conditionally parameterized at build time.
- **Memory Hierarchy**: TCM-centric architecture with integrated L0 Fetch cache; AXI-native integration.
- **Boundary Enforcement**: "Ship-to-SoC" IP boundary, strictly excluding FPGA-specific protocols (e.g., TLUL) and integration details.
